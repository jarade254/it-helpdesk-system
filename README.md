# 🖥️ IT Support Dashboard

A full-stack IT support dashboard built using:

- Node.js
- Express.js
- SQLite
- HTML/CSS/JavaScript

## 🚀 Features

- Create support tickets
- View all tickets
- Close tickets
- Delete tickets
- SQLite database storage
- REST API backend

## 📦 Technologies Used

- Node.js
- Express
- SQLite3
- HTML
- CSS
- JavaScript
